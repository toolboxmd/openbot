# ADR 0003: The product is named OpenBot

## Status
Accepted

## Context
CopilotKit already shipped `CopilotKit/openbot` with an Intelligence license. Another `next-open-ai/openbot` exists on npm. The name is the tweet.

## Decision
Repo and product name: OpenBot (`toolboxmd/openbot`). MIT, actually self-hosted, no CopilotKit lock-in. Do not copy their assets.

## Consequences
SEO and GitHub search collide. Copy must say actually open. Eyes and UI are original.
