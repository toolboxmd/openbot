# Issue tracker

GitHub Issues on [toolboxmd/openbot](https://github.com/toolboxmd/openbot).

Refer to tickets by **name**, not bare ids.

## Wayfinder

The map issue title starts with `[wayfinder:map]`.
Decision tickets use a type prefix in the title:

- `[research]` AFK
- `[prototype]` HITL
- `[grilling]` HITL
- `[task]` HITL or AFK

Parent of the decision tickets is the map (GitHub sub-issues).

Fog of war stays in the map under **Not yet specified** until it is sharp enough to ticket.

## Triage labels

Create these when labeling is available: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`, `bug`, `enhancement`.
Until then, put the state in the issue body.
