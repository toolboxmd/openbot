# Mission

OpenBot becomes a mode of the toolboxmd T3 Code fork, switched in the UI. It
keeps what is unique to it: Bots with profiles, Channels including group and
Bot-to-Bot, the chat-first design in `DESIGN.md`, and the Computer, one Docker
desktop per instance with a display per Bot. T3's core supplies harnesses,
sessions, continuation after restart, remote access and mobile, so OpenBot
retires its own harness plumbing as T3 covers each part.
